- Intervention and objection-handling playbooks
- Multi-channel outreach sequencing

- Guarded auto-execution mode
- Dynamic workflow composition/builder
- Reinforcement-style learning loops
- Cross-deal optimization and forecasting

## Not implemented by this documentation phase

This documentation restructuring does not implement autonomous execution, dynamic orchestration, real integrations, multi-channel operation at scale, forecasting, optimization, or any new workflow. The current implementation remains the four workflows listed in [workflow contracts](workflow-contracts.md), with deterministic mode as the default and human approval/tool controls unchanged.
